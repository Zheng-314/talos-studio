# Talos 直播间

一个能自己撑住一小时的直播画面：绿色系的二次元形象坐在桌前，桌上一台显示器在跑它自己的活，
下面是实时仪表盘。弹幕进来它会接，没人的时候它自己找事做。

抖音开播走的是「弹幕监听 → 本程序 → OBS 浏览器源 → 直播伴侣」这条线，和前面那套一样。

---

## 怎么跑

**先看效果，不接抖音**：双击 `1-演示模式.bat`，浏览器会自动打开 `http://127.0.0.1:8321/`。
它每 9–16 秒自己造一条弹幕，没人说话超过 38 秒就自己开一个活动。

**正式开播**，按顺序：

1. 打开抖音直播伴侣，进到自己的直播间
2. 用管理员身份运行 `1-弹幕监听.bat`（在 `talos-live` 目录里，监听程序开在 8888）
3. 双击 `2-正式开播.bat`
4. OBS 里新建「浏览器」源，地址 `http://127.0.0.1:8321/`，宽 1080 高 1920

浏览器的声音就是 Talos 的声音。OBS 的浏览器源要勾上「通过 OBS 控制音频」，
否则观众听不到，只能自己电脑响。

## 后台控制台

`http://127.0.0.1:8321/admin`，双击 `0-后台管理.bat` 会自动打开。

六个页面，改了立刻生效，不用重启：

| 页面 | 能干什么 |
|---|---|
| 总览 | 六个数（时长/token/弹幕/礼物/关注/开心度）、现在在干什么、让它说一句、一键触发活动、切回待机、工作日志 |
| 人设 | 三个角色的 system prompt（Talos / 阿刺 / 路人），改完保存，下一句生效 |
| 活动 | 三个活动的手动开关、自动找事做的总开关、空场多少秒后自己开工 |
| 形象 | 五套姿态预览，点一下立刻切换；可以上传 PNG 覆盖某一张 |
| 数据 | 完成活动数、平均每次回复的 token、开销估算、目标进度、最近 14 次模型调用（时间/token/问题）、最近弹幕 |
| 设置 | 目标名字与数值、接口地址、模型名、max_tokens、温度、三个角色的音色 |

API Key 在页面里永远是 `***`，只存本地 config.json，不会回显也不会外传。

## 三个活动

| 活动 | 怎么触发 | 屏幕上看到什么 |
|---|---|---|
| 小游戏 | 弹幕说「游戏」「玩」，或空闲自动 | 显示器里跑真的游戏，贪吃蛇会自己找路，打砖块自动挡板，反应力测试是机器手在打 |
| AI 头像 | 弹幕说「画一个…」「来张头像」，或空闲自动 | 显示器里出图，用的是 pollinations 的免费图像接口，不用 Key |
| 双 AI 对聊 | 弹幕说「吵一架」「对聊」，或空闲自动 | 它和「阿刺」互怼，两句话一轮，两个声音 |

游戏不是录屏，是 `web/games/` 里三个 HTML，真的在跑。
画图也不是假的，每次出图都会落到 `web/gallery/`，出图失败会重试三次。

## 指标怎么算

- **Token**：每次调模型返回的 `usage.total_tokens` 累加，不估算。
- **收到礼物**：弹幕事件里的礼物条数，附带的抖币没折算。
- **开心度**：基准 55。被夸、收到礼物、涨粉会涨；长时间冷场往下掉；之后缓慢回落。
  它还会影响说话语气，低于 35 会变短变平静，高于 75 会轻快一点。
- **今日目标**：互动 = 弹幕 1 分 + 礼物 2 分 + 关注 3 分 + 完成一个活动 5 分。

## 换形象

形象在 `assets/poses/`，五张同一个人物的不同姿态：`c_idle`、`c_talk`、`c_happy`、`c_think`、`c_surprise`。
程序按状态自动切：说话时用 talk，收礼物用 surprise，出图成功用 happy，画图时用 think，其余 idle。

要换人，只要提供同一构图、同一尺寸（1136×1900，透明底）的五张图，覆盖同名文件即可。
加一个新动作就多放一张 `c_xxx.png`，再到 `server.py` 里 `POSES` 加上名字。

## 文件

| 路径 | 作用 |
|---|---|
| `server.py` | 全部后端：弹幕、大脑、语音、活动、状态接口 |
| `web/index.html` | 整个舞台和仪表盘，一个文件 |
| `web/games/*.html` | 三个会自己玩的游戏 |
| `web/gallery/` | 生成的图 |
| `web/audio/` | 生成的语音，用完可以清 |
| `config.json` | Key、模型、声音、目标、人设 |

## 已知限制

- 语音是 edge-tts 的公共音色，不是专属声音。要专属得接 Fish Audio 那类克隆服务。
- 出图走 pollinations 免费接口，偶尔 503，会重试，但慢的时候要等十几秒。
- 写代码这类活动还没做，现在只有上面三个。加一个活动就是 `server.py` 里加一个 `activity_xxx` 函数。
- 弹幕监听依赖 `talos-live/tools/DouyinBarrageGrab`，那个程序要管理员权限、会开系统代理。
