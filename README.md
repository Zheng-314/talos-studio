# Talos Studio

把任何一张人物图，变成一个能自己开播的 AI 主播。

本地运行，不上传任何数据。选形象、写人设、一键开播，观众在弹幕里说话它就会回应，还能现场画画。

## 它解决什么

让一个不懂技术的人，二十分钟内拥有自己的 AI 直播间：

- 用自己的图，或者让 AI 按你的描述画一个
- 写几句人设，它就有自己的性格和说话方式
- 一键拉起 OBS、弹幕监听、直播引擎，剩下的在抖音直播伴侣里点开播
- 下播后能看到这一场的数据

## 四条链路

```
抖音直播间 → 直播伴侣 → 弹幕监听(8827) → 引擎(8321) → OBS → 虚拟摄像机 → 直播伴侣 → 抖音
```

| 部件 | 作用 |
|---|---|
| `talos-studio/app.py` | 管理界面：形象、人设、开播、数据（8400） |
| `talos-stream/server.py` | 直播引擎：接弹幕、生成回复、合成语音、回传画面（8321） |
| `talos-stream/web/` | 直播画面（1080×1920，给 OBS 当浏览器源） |
| 弹幕监听 | 接管系统代理抓抖音的弹幕，转成 WebSocket |

## 安装

1. 装 Python 3.10+（Windows 安装时勾选 Add python.exe to PATH）
2. 装 OBS Studio 和抖音直播伴侣
3. 双击 `启动.bat`，它会建环境、装依赖、打开浏览器

仓库里 `talos-stream/` 就是引擎目录，克隆下来直接跑，不用另外准备。

也可以直接用打好的安装包：`dist/Talos-Studio-Setup.exe`（需要系统里有 Python）。

## 用起来

**准备形象**：形象页传三张图（待机 / 干活 / 开心），自动抠底；或者写一句描述让 AI 画三张，挑一张装进去。

**写人设**：身份、能干什么、说话风格、边界。保存后自动生成提示词并写进引擎。

**调位置**：三个滑杆调人物大小和位置，右边实时预览，保存后直播画面立刻生效。

**开播**：开播页检查七项环境，全绿后点一键启动，然后在直播伴侣里点开播。

**看数据**：每场自动存档，首页能看到时长、弹幕、礼物、关注、Token 消耗。

## 观众能玩什么

- 弹幕说一句，它叫出你的名字再回答
- 说「画个…」，它现场写 SVG 画出来，挂在画面左侧
- 说「来局游戏」「找阿刺聊聊」，进对应活动（默认关闭，可在设置里开）

## 文件结构

```
talos-studio/
  app.py                管理端后端
  static/studio.html    管理端界面（单页）
  installer.py          安装器
  启动.bat              一键启动
  default-profile/      默认形象（新用户直接能用）
talos-stream/
  server.py             直播引擎
  web/index.html        直播画面
  web/games/            三个会自己玩的小游戏
  assets/poses/         当前形象的姿态图
  config.json           引擎配置（人设、模型、声音、排版）
```

## macOS

支持 macOS 13 以上（Intel 和 Apple 芯片）。抖音直播伴侣已有官方 Mac 版。

```bash
bash build_mac.sh     # 产出 dist/Talos Studio.app
```

也可以直接跑源码：`./启动.command`。

**一个已知缺口**：弹幕采集用的是 Windows 的 .NET 程序，Mac 上跑不了。所以 Mac 版目前能开播、能显示画面、能画画，但弹幕互动还接不上。替代方案是用 mitmproxy 抓同一路流量，还没做。

GitHub Actions 已经配好（`.github/workflows/build.yml`），推 tag 会自动出 Windows 和 macOS 两个产物。

## 已知限制

- 形象是静态图，三种姿态靠切换，做不到 Live2D 的转头和口型
- 弹幕监听靠接管系统代理，跟系统代理类软件会冲突（已支持配置上游转发）
- 出图走免费接口，有频率限制；SVG 画画走模型，稳定但风格是矢量插画
- 电脑开播需要抖音账号满足粉丝和实名要求
